1、方法

什么是方法?应用场景?好处?

**方法：**程序中的独立功能，也是最小的执行单元

**应用场景：**经常使用的代码打包，放在方法当中

好处：提高了程序的复用性和可维护性

方法的格式和执行流程

方法的格式

public static 返回值类型方法名(参数1，参数2...){
    方法体;
    return 返回值;
}

注意点：

  1. 方法与方法之间是平级关系，不能互相嵌套
  2. 方法不会主动运行，需要被调用
  3. 小括号中的参数需要（形参和实参）一一对应（个数，类型）

方法的执行流程

实参传给形参

return:结束方法，将结果返回给调用处

定义方法的小诀窍

  1. 观察在大段的代码当中，反复使用的独立功能是什么?反复使用+独立功能
  2. 这个独立功能，需要什么才能完成?
  3. 方法的调用处，是否需要这个独立功能的结果继续做其他事情?

方法的重载

  1. 同一个类中，定义了多个同名的方法，这些方法具有类似的功能
  2. 每个方法具有不同的参数类型和参数个数，这些同名的方法，就构成了重载关系
  3. 简单理解:同一个类，方法名相同，参数不同的方法，无需看返回值
  4. 方法重载一般不会写成形参不同的形式

方法的注意事项

  1. 方法不调用就不执行
  2. 方法与方法之间是平级关系，不能嵌套定义
  3. 调用方法会优先调用形参和实参一一对应的，如果没有才会进行隐式转换
  4. return:1.结束方法2.将结果返回给调用者
  5. void:没有返回值，可以省略return不写，如果不省略，return后面不能写具体数据，仅表示结束方法

2、JAVA原理

JAVA的运行机制

.java文件编译成class文件后运行在JVM（java虚拟机）中

  1. Java程序运行的过程是怎么样的? Java文件-->class字节码文件-->结果
  2. Java是直接运行在操作系统里面的吗? 不是，是运行在虚拟机里面的
  3. 虚拟机的好处是什么? 利用虚拟机可以实现跨平台
  4. **为什么要跨平台? 写一套代码，**可以在任意的操作系统中运行

JAVA的内存管理

**内存：**软件在运行时，用来临时存储数据的

**内存地址：**一个编号，用来快速查找内存中的数据，从而快速地管理内存空间

JAVA中的内存分配

  1. 栈内存：方法
  2. 堆内存：new关键字
  3. 方法区：字节码信息（class）;JDK7永久代实现，JDK8+元空间实现，从虚拟机内部移到本地内存。存储字节码信息、常量、静态变量
  4. 本地方法栈
  5. 程序计数器

方法区只存储不运行，运行时进栈运行

**基本数据类型：**变量里面记录的是真实的数据，传递的也是真实的数据

总结

1、JAVA虚拟机把内存分成了几个部分？

栈、堆、方法区、本地方法栈、程序计数器

2、栈、堆、方法区的作用？

  • 栈：方法
  • 堆：new关键字
  • 方法区：字节码文件（.class）

3、基本数据类型在内存中的特点？

记录的是真实的数据，传递的也是真实的数据（值传递）

4、引用数据类型在内存中的特点

记录的是地址值，传递的也是地址值（引用传递）
