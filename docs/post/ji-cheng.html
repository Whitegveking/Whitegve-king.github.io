继承

什么是继承？继承的好处？

  • 继承是类与类之间的一种父子关系，Java中提供关键字extends，用于建立类与类之间的关系
  • 可以吧多个子类中重复的代码抽取到父类中，提高代码的复用性
  • 子类可以在父类的基础上，增加其他的功能，使子类更强大

总结

1、什么是继承？

面向对象三大特征之一，可以让类跟类之间产生父子关系

2、继承的作用是什么

  • 操作：多个子类中重复的代码抽取到父类，子类可以直接使用
  • 好处：减少代码冗余，提高代码复用性

3、继承的格式？

public calss 子类 extends 父类 {}

4、继承后子类的好处

  • 子类可以得到父类的属性和行为，子类可以使用
  • 子类可以在父类的基础上新增其他功能，子类更强大

继承的特点

JAVA只支持单继承，不支持多继承，但支持多层继承

单继承：一个子类只能继承一个父类

不支持多继承：子类不能同时继承多个父类

多层继承：分为直接父类和间接父类

JAVA中的顶级父类为：Object，每一个类都直接或者间接继承于Object

方法的重写
  • 方法重写：在子类中，把父类的方法再写一遍，方法声明保持一致
  • 使用场景：如果父类的方法不能满足子类的要求了，子类中可以把该方法再重写一遍

注意事项和要求
  1. 重写方法的名称、形参列表必须与父类中的一致，方法体按照实际需求书写。
  2. 了解:子类重写父类方法时，访问权限子类必须大于等于父类(空着不写<protected<public)
  3. 了解:子类重写父类方法时，返回值类型子类必须小于等于父类
  4. 建议:重写的方法申明和父类保持一致即可
  5. final修饰类为最终类，里面所有的方法不能被重写
  6. private私有方法，static静态方法，final最终方法不能被重写

总结

1.继承中成员方法的特点:

  • 书写规则:抽取子类中共性的行为
  • 调用规则:就近原则
  • this调用:先访问本类，再访问父类
  • super调用:直接访问父类

2.什么是方法重写**?**

  • 在继承体系中，子类出现了和父类中一模一样的方法声明
  • 我们就称子类的这个方法是重写的方法
  • 重写的方法上需要加@Override注解，校验重写的语法是否正确

3.什么时候使用方法重写?

当父类的方法不能满足子类要求的时候，需要进行方法重写

4.重写方法有哪些基本要求?

子类重写的方法申明跟父类保持一致

private私有方法、static静态方法、final最终方法不能被重写
