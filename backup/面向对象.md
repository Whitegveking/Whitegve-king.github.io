# 面向对象基础

## 什么是面向对象？

**对象**：把相关的**数据**和**方法**组织为一个**整体**来看待

**面向对象**：利用**对象**进行软件开发

## 类和对象

用一个类来描述狗狗

```java
package object;

public class Dog
{
    String name;
    int age;
    double weight;
    String color;
}
```

```java
package object;

public class ObjectDemo1
{
    public static void printDogInfo(Dog dog)
    {
        System.out.println("小狗的名字是：" + dog.name);
        System.out.println("小狗的年龄是：" + dog.age);
        System.out.println("小狗的体重是：" + dog.weight);
        System.out.println("小狗的颜色是：" + dog.color);
    }
    static void main()
    {
        // 创建对象，记录第一只小狗的信息
        Dog dog1 = new Dog();
        dog1.name = "旺财";
        dog1.age = 3;
        dog1.weight = 5.5;
        dog1.color = "黄色";
        printDogInfo(dog1);
    }
}
```

**`new`**：创建一个大空间

**`Dog`**：管理狗狗的信息

**`dog1`**：大空间的名字

- 描述一类事物的类叫`Javabean`类
- 带有`main`方法的类叫测试类
- `Javabean`类可以写属性和行为

## 面向对象中的数据安全问题

### `private`关键字

是一个权限修饰符，可以修饰成员变量和成员方法 

**特点**：一旦被`private`修饰，只能在本类中才能访问，外界无法访问

```java
package ObjectDeno4;

public class Dog
{
    /*
    * 小狗有属性:姓名、年龄。
      行为:吃骨头
      实现以下需求
      要求1:小狗的年龄:0~15岁
      要求2:打印小狗所有的信息:小白，2岁
      要求3:调用吃骨头的方法打印效果:2岁的小白，正在吃骨头
    * */
    private String name;
    private int age;

    public void setName(String name)
    {
        this.name = name;
    }

    public void setAge(int age)
    {
        if (age < 0 || age > 15) {
            System.out.println("小狗的年龄不合法");
            return;
        }
        this.age = age;
    }

    public void printDogInfo()
    {
        System.out.println(this.name + "，" + this.age + "岁");
    }

    public void eatBone()
    {
        System.out.println(this.age + "岁的" + this.name + "，正在吃骨头");
    }
}
```

```java
package ObjectDeno4;

public class Test
{
    static void main()
    {
        Dog dog1 = new Dog();
        dog1.setName("小白");
        dog1.setAge(2);
        dog1.printDogInfo();
        dog1.eatBone();
    }
}
```

### 总结

1. **`private`**关键字:是一个权限修饰符可以修饰成员变量和成员方法。

   **特点**:被private修饰的成员只能在**本类**中才能访问。

2. 针对private修饰的成员变量，需提供以下操作:

   提供setXxx(参数)，给成员变量赋值，用public修饰

   提供"getXxx()"，获取成员变量的值，用public修饰

## `this`关键字

**默认**：就近原则，在方法当中直接使用变量查找顺序：先找局部变量，再找成员变量

`this`的作用：可以区分局部变量和成员变量

```java
System.out.println(age); //触发就近原则
System.out.println(this.age); //使用成员变量
```



直接使用成员变量加`this`前缀

```java
package ObjectDemo5;

public class Student
{
    private int age;

    public int getAge()
    {
        return age;
    }

    public void setAge()
    {
        int age = 10;
        // 就近的局部变量优先级高于成员变量
        System.out.println(age);
        System.out.println(this.age);
    }
}
```

```java
package ObjectDemo5;

public class Test
{
    static void main()
    {
        Student student1 = new Student();
        student1.setAge();
    }
}
```

## 构造方法

- **构造方法也叫做构造器、构造函数**
- **作用**：在创建对象的时候给成员变量进行初始化

### 特点：

1. 方法名与类名相同，大小写也要一致
2. 没有返回值类型，连void都没有
3. 没有具体的返回值（不能由`return`带回数据结果）

### 执行时机：

1. 创建对象的时候由虚拟机调用，不能手动调用构造方法
2. 每创建一次对象，就会调用一次构造方法

```java
package ObjectDemo6;

public class Student
{
    private String name;
    private int age;
    private String gender;
    private double height;

    public Student()
    {
        // 无参构造方法
        System.out.println("无参构造方法被调用");
    }

    public Student(String name, int age, String gender, double height)
    {
        // 有参构造方法
        this.name = name;
        this.age = age;
        this.gender = gender;
        this.height = height;
        System.out.println("有参构造方法被调用");
    }

    // set/get
    public void setName(String name)
    {
        this.name = name;
    }

    public String getName()
    {
        return name;
    }

    public void setAge(int age)
    {
        this.age = age;
    }

    public int getAge()
    {
        return age;
    }

    public void setGender(String gender)
    {
        this.gender = gender;
    }

    public String getGender()
    {
        return gender;
    }

    public void setHeight(double height)
    {
        this.height = height;
    }

    public double getHeight()
    {
        return height;
    }

    public void getInfo()
    {
        System.out.println("姓名：" +getName() +
                "，年龄：" + getAge() +
                "，性别：" + getGender() +
                "，身高：" + getHeight());
    }
}
```

```java
package ObjectDemo6;

public class Test
{
    static void main()
    {
        Student student1 = new Student();
        student1.getInfo();
        Student student2 = new Student("小明", 18,"男", 1.75);
        student2.getInfo();
    }
}
```

### 构造方法注意事项

- 如果没有定义构造方法，系统将给出一个**默认的无参数构造方法**
- 如果自己写了任意构造方法（不论有无参数），系统将**不再提供**默认的构造方法
- 带参构造方法和无参数构造方法，两者方法名相同，但是参数不同，这叫做构造方法的重载
- **习惯**：无论是否使用，都手动书写无参数构造方法，和带有全部参数的构造方法
